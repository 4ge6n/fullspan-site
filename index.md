# FullSpan

iPhone Duo の Safari で、Web ページをボタン列の下まで広げて表示する Safari 拡張機能です。
A Safari extension that lets web pages extend under Safari's button column on iPhone Duo.

- [プライバシーポリシー / Privacy Policy](privacy)
- サポート / Support: [GitHub Issues](https://github.com/4ge6n/fullspan-site/issues)

## 使い方 / How to use
1. 設定 > アプリ > Safari > 機能拡張 で FullSpan をオンにする
2. 「すべての Web サイト」で許可する
3. アウターディスプレイまたは Split View で Safari を開く
4. Split View で Safari を左右に動かしたら、ページを横にフリックして切り替える

1. Settings > Apps > Safari > Extensions: turn on FullSpan
2. Allow it on all websites
3. Open Safari on the outer display or in Split View
4. In Split View, flick the page sideways after moving Safari to the other side
